MeetAI is a full-stack SaaS app for running video meetings with AI agents. Users create agents with custom instructions, schedule meetings, and the agent joins the call as a real-time voice participant powered by the OpenAI Realtime API over Stream Video. Built with Next.js 15, React 19, tRPC, TanStack Query, Drizzle ORM on Neon Postgres, Better Auth, and Tailwind/shadcn UI.
